# Prerequisities

Python 3.x and a running mySQL server

# Database (for the developers):

## Database in mySQL

Create a database called enterprise_db and set up the users table

## Configure the DB connection

open app.py and update the get_db_connection() function with the correct MySQL host, user and password for your environment

# Install dependencies

- pip install flask 
- pip install mysql.connector
- pip install werkzeug.security
- pip install os

These will also be in the requirements.txt file.

# Run the app

python app.py from Login-Py, runs on http://localhost:5000. Ensure you are doing this from the Terminal.

# Access

Go to: http://localhost:5000/login.
