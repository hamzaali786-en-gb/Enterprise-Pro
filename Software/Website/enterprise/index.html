About the Project

This project evaluates crowd engagement during BD25 UK City of Culture events using multimodal data including images, video, audio, and time-series records. Machine learning models are applied for crowd counting, engagement analysis, comparison, and prediction.

Core Features

Multimodal Data

2D/3D images, videos, audio, and time-series data integration.

Machine Learning

Crowd counting, engagement analytics, prediction models.

Secure Web Platform

3-tier architecture with controlled and secure access.

How It Works

Data Collection

Capture images, videos, and sensor data from live events.

Processing

Preprocess and clean multimodal datasets.

Analysis

Apply ML models for crowd detection and engagement scoring.

Insights

Visualize trends and generate actionable insights.

Use Cases

Event Monitoring

Track crowd size and engagement in real time.

Urban Planning

Support decision-making using crowd analytics.

Safety & Security

Identify risks and ensure safe event environments.
